## Projeto em destaque

### Affiliate Link Manager

Projeto fullstack para gerenciamento de links de afiliados e URLs encurtadas.

A aplicação permite cadastrar usuários, criar links personalizados, organizar links por campanha, acompanhar cliques, ativar/desativar links e definir datas de expiração. O projeto foi desenvolvido como evolução de um URL shortener simples, com foco em boas práticas de backend e integração fullstack.

**Stack:** Node.js, Express, PostgreSQL, Prisma, Docker, JWT, Jest, Swagger, React, Vite e Render.
